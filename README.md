# Spandana VR — Portfolio

Personal portfolio of **Spandana VR**, Information Science & Engineering student at NMIT Bengaluru, focused on Machine Learning, Deep Learning and Explainable AI.

🔗 **Live:** https://santhosh12133.github.io/spandana_portfolio/

## Tech
Plain HTML, CSS and JavaScript. No build step, so it works directly on GitHub Pages.

## Structure
```
index.html                    page content
style.css                     styles (lavender theme, responsive)
script.js                     menu, typing effect, scroll animations
assets/spandana.jpg           profile photo
assets/Spandana_VR_Resume.pdf resume (Download Resume button)
```

## Deploy on GitHub Pages
Settings → Pages → Source: **Deploy from a branch** → Branch: **main** / **(root)** → Save.

## Updating content
All text lives in `index.html`. To replace the resume, overwrite `assets/Spandana_VR_Resume.pdf` with the same file name.
